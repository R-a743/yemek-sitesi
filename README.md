# yemek-sitesi
🍽️ TheMealDB - Yemek Portalı
TheMealDB API kullanılarak geliştirilmiş, kullanıcıların dünya mutfağından çeşitli yemek tariflerini aramasına, filtrelemesine ve favorilerine eklemesine olanak tanıyan modern bir web uygulamasıdır.

CANLI DEMO :   https://r-a743.github.io/food-recipe-portal-concept/

🚀 Özellikler
Dinamik Arama: Yemek ismine göre anlık arama yapabilme.

Türkçe-İngilizce Anahtar Kelime Desteği: "Tavuk", "Çorba", "Et" gibi Türkçe aramaları otomatik olarak API uyumlu İngilizce terimlere çevirir.

Karanlık/Aydınlık Tema: Kullanıcı tercihine göre değişen ve localStorage ile kaydedilen tema desteği.

Favori Sistemi: Beğenilen yemekleri yıldız ikonuna tıklayarak favorilere ekleme ve kalıcı olarak tarayıcıda saklama.

Detay Paneli: Seçilen yemeğin hazırlanış talimatlarını ve büyük görselini içeren detay bölümü.

Sıralama ve Filtreleme: Sonuçları A-Z veya Z-A şeklinde alfabetik olarak sıralama.

Daha Fazla Yükle: Büyük veri setlerini "Load More" mantığıyla (sayfa başına 6 ürün) parçalı olarak görüntüleme.

Responsive Tasarım: Mobil cihazlar ve masaüstü ekranlar için tam uyumlu arayüz.

🛠️ Kullanılan Teknolojiler
HTML5: Semantik yapı ve içerik düzeni.

CSS3: Özel değişkenler (CSS Variables), Flexbox ve Responsive (Media Queries) tasarım.

JavaScript (ES6+): Fetch API, Async/Await yapısı ve DOM manipülasyonu.

TheMealDB API: Ücretsiz yemek tarifi veri kaynağı.
